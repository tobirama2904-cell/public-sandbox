# public-sandbox

Открытая **публичная** песочница для экспериментов: небольшие примеры, прототипы, тестовые страницы и обучающий код.

## Что здесь есть

- Эксперименты и черновые примеры
- Тестовые страницы и сниппеты
- Материалы, которыми не жалко поделиться

## Использование

Репозиторий публичный — код можно свободно смотреть, копировать и использовать по лицензии [MIT](LICENSE).
